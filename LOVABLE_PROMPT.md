LOVABLE PROMPT — COMMUNITY HELP HUB

Build a modern, professional, mobile-first community support web app called “Community Help Hub” with the tagline “Neighbours helping neighbours.” Use navy, teal, white, and pale-mint colours, accessible contrast, rounded cards, subtle shadows, clear typography, and responsive layouts.

Problem: community information is often scattered across group chats, noticeboards, and word of mouth. Target users are residents, students, parents, volunteers, and local organisations.

Include:
1. A landing page with hero statement and “Create a post” / “Explore posts” actions.
2. A community board with sample posts, category labels, dates, and general areas.
3. Categories: Lost & Found, Study Support, Recycling, and Community Notices.
4. Search by title, description, category, or area.
5. Category filters and sorting by newest, oldest, or category.
6. A form to create posts with title, category, general location, and description; validate required fields and show confirmation.
7. Copy post details and allow deleting posts created by the current user in the demo.
8. Responsive mobile-first design, accessible labels, keyboard-friendly controls, and useful empty states.
9. Visible safety reminders: do not share phone numbers, home addresses, passwords, or sensitive details publicly; verify notices and meet in safe public places.
10. Sample posts clearly identified as demonstration content.

Make interactions functional, not decorative. If there is no backend, use browser local storage and clearly state that posts are only saved in the current browser and are not shared with other users. Do not claim there is a live database, login, AI verification, or messaging unless implemented.

Deliver complete source code and a README explaining features, how to run the app, limitations, and GitHub Pages deployment. Keep the project understandable for a beginner and ready to deploy as a static site.
