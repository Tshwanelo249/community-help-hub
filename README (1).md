# Community Help Hub

A responsive front-end prototype for the ASA 23 Shark Tank app pitch. It brings community notices, lost-and-found posts, study support, and recycling information into one simple board.

## Features
- Responsive mobile and desktop design
- Search by title, description, category, or area
- Filter by category and sort posts
- Create a post with form validation
- Copy post details and delete posts created in the demo
- Sample posts and browser `localStorage`
- Visible privacy and safety reminders

## Run locally
Open `index.html` in a modern web browser. No build tools or API keys are required. Try searching, filtering, creating a post, copying details, and refreshing the page.

## GitHub Pages deployment
1. Create a GitHub repository, e.g. `community-help-hub`.
2. Upload `index.html` and `README.md` to the repository root.
3. Go to **Settings → Pages**.
4. Under **Build and deployment**, choose **Deploy from a branch**.
5. Select branch `main` and folder `/(root)`, then save.
6. Wait for the URL to appear in the Pages section and test it on desktop and mobile.

## Limitations
This is a front-end student prototype. Posts are saved only in the current browser and are not shared with other users. There is no login, shared database, moderation service, messaging, or live verification. Sample posts are illustrative, not verified. Do not publish private information.

## Future improvements
A production version would need secure accounts, a backend database, moderation and reporting, privacy controls, and trusted community partners.
